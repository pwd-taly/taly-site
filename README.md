# Taly's site

Static personal developer site for `taly.runs-on.dev`.

## Deploy with GitHub Pages

1. Push these files to a public GitHub repository.
2. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
3. Add `taly.runs-on.dev` as the custom domain. The included `CNAME` file will keep it configured.
4. In the `runs-on.dev` registry record, point the name at `pwd-taly.github.io` using a CNAME record (the exact JSON field is documented in the registry README).
